历史记录

点任意一句，录音跳到那里播放。

设置

云同步（Google Drive）

同步 API key、识别和翻译设置、术语表、历史记录的文字。录音不同步，只在录制的那台设备上。字号等显示设置每台设备各自保存。数据存在你 Drive 的应用隐藏文件夹里，只有本网页能读。

API Key

Deepgram：console.deepgram.com 注册，用于实时逐词识别。Groq：console.groq.com 注册，不用绑卡，用于按句识别（Deepgram 连不上时自动用它）和翻译。Gemini：aistudio.google.com 里 Get API key。硅基流动：cloud.siliconflow.cn。识别至少要有 Deepgram 或 Groq；翻译至少要有一家可用。

识别

实时：英文边说边出，一句说完马上翻译。按句：等老师停顿后整句出来，慢一些但免费。灵敏度只对按句有效：教室吵、识别出很多杂音就调低；老师声音小、经常漏句就调高。

翻译模型（从上往下依次尝试，限流自动换下一个）

模型名一般不用改。哪家改了模型名或下线了，在这里改成新名字。

术语表

每行一个：英文 = 中文。只写英文也行（只帮助识别）。# 开头是注释。识别和翻译时自动带上，只发当前句子里出现的词。

显示

开始时"保存"开关的默认状态

模型对比

同一段英文发给所有开启的模型，并排看译文和速度。可以从历史记录里复制真实课堂内容来测。

存储

天
开了云同步时，录音每 3 分钟一段传到 Drive；超过这个天数的课，本机只删已经传上去的录音，要听时自动从云端下载。填 0 就是传完就删。没开云同步时不会删。

查书

精修：下课后把整节课录音重新识别一遍（更全、区分说话人），再结合上下文重新翻译。需要时才点，会用一点 Deepgram 额度。
点任意一个词，录音从那里开始播。

设置

云同步（Google Drive）

录音和文字记录放在 Google Drive 的"课堂同传"文件夹里，每节课一个子文件夹，在电脑上打开 Drive 就能直接听、下载。在这里删一节课，那个文件夹会进 Drive 回收站。API key、术语表等设置和同步用的数据存在 Drive 隐藏的应用数据里，别人看不到。字号等显示设置每台设备各自保存。

API Key

Deepgram：console.deepgram.com 注册，用于实时逐词识别。Groq：console.groq.com 注册，不用绑卡，用于按句识别（Deepgram 连不上时自动用它）和翻译。Gemini：aistudio.google.com 里 Get API key。硅基流动：cloud.siliconflow.cn。识别至少要有 Deepgram 或 Groq；翻译至少要有一家可用。

识别

每台设备各自记住，不跟云同步。主界面"开始"旁边也能切换。
实时字幕换人时另起一行，标"说话人 1/2…"（只对实时识别有效）
实时和精修都自动认语言（中文、印地语、西班牙语等 50 多种）：中文翻成英文，其他语言翻成中文，原文旁标出语言。口音重的英文可能被认成别的语言，不好用就关掉
实时：英文边说边出，一句说完马上翻译。按句：等老师停顿后整句出来，慢一些但免费。灵敏度只对按句有效：教室吵、识别出很多杂音就调低；老师声音小、经常漏句就调高。

翻译模型（从上往下依次尝试，限流自动换下一个）

选了就先用它，被限流或出错时还是按下面的顺序换别的，不会翻不出来。
上课点"提示"时先用它。默认 gpt-oss-120b（快），不行按顺序换别的；想对比答案可以在卡片上"换模型再问"。
模型名一般不用改。哪家改了模型名或下线了，在这里改成新名字。

资料（规范和课本）

导入在电脑上做好的资料文件（比如 资料.json.gz，含 B149 和这学期的 Unit 课本）。只存在这台设备和你自己 Google Drive 的隐藏数据里（不公开），开了云同步，别的设备同步一次就自动下载。上课点"提示"时自动查，有相关条款就照原文回答并标出处；顶上"查书"可以直接搜原文。

术语表

每行一个：英文 = 中文。只写英文也行（只帮助识别）。# 开头是注释。识别和翻译时自动带上，只发当前句子里出现的词。

显示

字幕里标出下面勾选的声音（没人说话的待机时段总会标）
开始时"保存"开关的默认状态

模型对比

同一段英文发给所有开启的模型，并排看译文和速度。可以从历史记录里复制真实课堂内容来测。

存储

天
开了云同步时，录音每 3 分钟一段传到 Drive；超过这个天数的课，本机只删已经传上去的录音，要听时自动从云端下载。填 0 就是传完就删。没开云同步时不会删。

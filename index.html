API Key（只存在本设备浏览器里）

Groq：console.groq.com 注册，不用绑卡。Gemini：aistudio.google.com 里 Get API key。硅基流动：cloud.siliconflow.cn。Groq 用于识别，必须有；翻译至少要有一家可用。

识别

教室吵、识别出很多杂音就调低；老师声音小、经常漏句就调高。
